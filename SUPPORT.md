# Support

Valtors projects are maintained on a best-effort basis.

- **Bug:** open a reproducible issue using the bug form.
- **Question or idea:** use GitHub Discussions when enabled.
- **Security vulnerability:** follow `SECURITY.md`; do not disclose it publicly.
- **Large change:** open a proposal before writing a substantial pull request.

Please include the project version or commit, operating system, runtime version, configuration with secrets removed, reproduction steps, expected result, and actual result.

Maintainers may close incomplete, duplicate, out-of-scope, abusive, promotional, or automated-noise submissions.
